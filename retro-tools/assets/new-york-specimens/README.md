Open [the gallery](index.html) locally to review the four images together. The images contain fictional sample information and permanent SPECIMEN / NOT VALID FOR IDENTIFICATION markings. Back designs use decorative circuit illustrations with no machine-readable data.

These are flattened concept PNGs, not editable Badge Studio templates. The supplied official sample cards informed the general ivory/blue palette and front/back format; the generated compositions are original.

Generated with the built-in GPT image tool. Exact prompts are saved in [prompts.json](prompts.json).
