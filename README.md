# Nightcode

- [`nightcode-app/`](nightcode-app/) is the NightCode desktop file workstation: DOS-style shell, file preview, copy and duplicate tools, URL downloads, GitHub and Supabase uploads, and an embedded live internet browser.
- [`retro-tools/`](retro-tools/) contains Disk Dude and Netcon.
- [`abandonware/`](abandonware/) is **Retro USB**, a kit that fills a USB stick with DOSBox, free DOS classics, your own DOS games and strategy guides.
