# Nightcode

- [`nightcopy-web/`](nightcopy-web/) is the NightCopy hosted file console: a sleek DOS shell, dual file panes, local folders, transfer queues, duplicate/ZIP tools, Google Drive and private Supabase storage. Open [NightCopy](https://nightcopy.coletechsystems.com) or its [cloud setup guide](https://nightcopy.coletechsystems.com/SETUP.html).
- [`nightcode-app/`](nightcode-app/) is the NightCode desktop file workstation: DOS-style shell, file preview, copy and duplicate tools, URL downloads, GitHub and Supabase uploads, and an embedded live internet browser.
- [`retro-tools/`](retro-tools/) contains Disk Dude and Netcon.
- [NetCon 16-bit art kit](retro-tools/assets/netcon-kit/README.md) contains GPT-generated branding, UI frames, button states, native cursors and a preview gallery.
- [`abandonware/`](abandonware/) is **Retro USB**, a kit that fills a USB stick with DOSBox, free DOS classics, your own DOS games and strategy guides.
